# Implementation Plan: v0.7 Prestige Patch

**Branch**: `007-v07-prestige-patch` | **Date**: 2026-06-12 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/007-v07-prestige-patch/spec.md`

## Summary

v0.7 introduces a Prestige system (reel+currency reset with icon selection), replaces Lock Column with Block Column (column exclusion instead of carry-over), adds magic phase color-coded win hints (green/yellow borders per definitionId), multiplies all magic ability costs by the spin multiplier, locks the multiplier toggle during magic phase, replaces the spin result modal with a toast notification, rebalances the market (3-copy cap, apple bundle repricing, food starting amount 100→10), and overhauls the Reel tab (grouped icon display, enable/disable removed, prestige UI). State version bumps 5→6, removing `disabledIconIds` and `lockedColumns`, adding `blockedColumns`.

## Technical Context

**Language/Version**: TypeScript 5.6 (strict mode) + React 18.3

**Primary Dependencies**: Vite 6, Tailwind CSS 3, Vitest 2, @testing-library/react 16 (no new runtime dependencies)

**Testing**: Vitest + @testing-library/react + user-event; jsdom environment. Existing suites: `tests/unit/*`, `tests/integration/*`.

**Constraints**: No new runtime dependencies. Highlight map derivation is O(n) per cell across 5 columns of 3 rows — negligible. Prestige icon selection is pure local state in `ReelView`.

**Scale/Scope**: Single-player browser game; all state in memory + localStorage. ~14 source files touched plus tests.

Add `computeHighlights` helper (pure function, defined outside component):
```ts
function computeHighlights(
  grid: MagicCell[][],
  blockedCols: number[],
): Map<string, 'green' | 'yellow'> {
  const activeCount = grid.length - blockedCols.length
  const defColSets = new Map<string, Set<number>>()
  grid.forEach((col, colIdx) => {
    if (blockedCols.includes(colIdx)) return
    col.forEach((cell) => {
      const defId = cell.icon.definitionId
      if (defId === 'blank') return
      if (!defColSets.has(defId)) defColSets.set(defId, new Set())
      defColSets.get(defId)!.add(colIdx)
    })
  })
  const map = new Map<string, 'green' | 'yellow'>()
  defColSets.forEach((colSet, defId) => {
    if (colSet.size === activeCount) map.set(defId, 'green')
    else if (colSet.size === activeCount - 1) map.set(defId, 'yellow')
  })
  return map
}
```
