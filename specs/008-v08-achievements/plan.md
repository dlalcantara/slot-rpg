# Implementation Plan: Version 0.8 — Achievements

**Branch**: `008-v08-achievements` | **Date**: 2026-06-13 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/008-v08-achievements/spec.md`

## Summary

Add an Achievements system (15 achievements with unlock dialogs and a persistent tab) while removing the x10/x100 spin multipliers, expanding the market purchase cap from a hard limit of 3 to the dynamic `qty × 2 < reel_size` condition, and replacing the 100-Crown win endpoint with open-ended play. The former "Master of Elements" special effect is retired in favour of a new achievement of the same name.

## Technical Context

**Language/Version**: TypeScript 5.6 / React 18.3 (Vite 6, Tailwind CSS 3)

**Primary Dependencies**: React 18, Vite 6, Tailwind CSS 3, Vitest 2, @testing-library/react 16

**Storage**: localStorage via `src/game/persistence.ts`

**Testing**: Vitest + @testing-library/react — existing suites in `tests/unit/` and `tests/integration/`

**Target Platform**: Browser (GitHub Pages CDN); mobile-first 720 × 1280 px

**Project Type**: Single-page web application — no backend, no external APIs

**Performance Goals**: Bundle ≤ 250 KB gzip; spin computation ≤ 16 ms; page load ≤ 3 s on Slow 3G

**Constraints**: Achievement state must persist in localStorage without breaking existing save format; no new npm dependencies

**Scale/Scope**: 15 achievements, ~5 new source files, ~8 modified files; single localStorage schema migration step

## Constitution Check

- [x] **I. Code Quality** — TypeScript strict mode already on. New `achievements.ts` module uses a discriminated string union; no `any` casts planned.
