# Implementation Plan: Slot Machine RPG — MVP

## Summary

A browser-based slot machine RPG where the player spins a 3×5 icon grid to earn currencies (Food, Copper/Silver/Gold, Crowns), buys icons from a Market to grow their Reel, and wins by accumulating 100 Crowns before running out of Food. Game state persists via `localStorage`; a Hard Reset button and a game-over replay CTA are always available. Built as a React 18 + TypeScript (strict) single-page app, bundled with Vite, deployed to GitHub Pages.

## Technical Context

**Language/Version**: TypeScript 5.x (strict mode), targeting ES2020

**Primary Dependencies**: React 18, Vite 5 (with `@vitejs/plugin-react`), Tailwind CSS, Vitest, React Testing Library, ESLint + `@typescript-eslint`, `gh-pages` (deploy)

**Storage**: Browser `localStorage` (single JSON blob, key `slot-rpg-state`)

**Testing**: Vitest (unit + integration), React Testing Library

**Target Platform**: GitHub Pages (static, no server); Mobile-first at 720×1280 px; Desktop ≥ 1280 px

**Project Type**: Single-page web application

**Performance Goals**: Initial load ≤ 3 s on simulated 3G; spin computation ≤ 16 ms; JS bundle ≤ 250 KB gzipped

**Constraints**: No server-side logic; no audio (MVP); no save/load UI (automatic); offline-capable after first load; asset paths must use Vite `base` config for GitHub Pages subdirectory (`/slot-rpg/`)

**Scale/Scope**: Single-player; single session per browser tab; reel size grows with market purchases (no enforced limit)
