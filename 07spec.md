Version 0.7 "Prestige Patch"

Market Rebalance:

Only allow purchase of up to 3 instances of the same icon.  Because the starting deck already has apple, air, water, and copper, there should only be 2 instances available in the market for those icons.  The others have 3 instances available in the market.

Rebalance 3x Apple and 12x Apple.  It should now be 2x Apple for 1 silver, and 3x Apple for 1 gold.

Starting Currency: Should now be 10 food, 10 air, 10 water, 0 of everything else

SPIN Tab:

During the Magic Phase:
  Use color coding for the user to easily see icons that are winning combination.  If an icon is found in all columns, use a green border around all cells of that icon.  If an icon is found in all columns except for 1, use a yellow border around all cells of that icon.
  do not allow the user to change the x1|x10|x100 toggle.
  The cost of abilities are now multiplied based on that toggle.  For example respinning when toggled to x100 requires x100 air for the first respin.

  Replace the Earth ability (lock column).  It is now "Block Column".  The user can use this action to select a column that will be blocked.  Blocking a column removes all its icons from the result.  But it also removes that column from being required to have an icon to get the reward.  The first Block Column costs 1 Earth, second block column costs 2 earth and so on.  Only 4 columns can be blocked.  Block column only lasts for that spin and resets upon claiming.

  Upon claim: Remove the results dialog. Replace it with a toast notification (small unobtrusive temporary message)

REEL Tab:

  Display Icons in order, grouping similar icons together so that users can easily see if they have 3 copies of an icon.

  Remove Enabling / Disabling of Icons.

  Instead, add a Prestige Button.  Prestige is only available when the user has 4 or more icons with 3 copies each.  Upon Prestige, the user selects at least 4 unique icons of those with 3 copies each; the user can select more if they want.  Afterwards reset the currency back to 10 food, 10 air, 10 water and 0 of everything else. Retain the spin counter value.  The User Reel should now reset to 1 copy of each selected icon.

  Include a brief explanation about prestige in the Reels tab.
